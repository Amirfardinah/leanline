# Leanline

A calorie tracker for losing weight: scan food barcodes, search foods online, log meals, and follow a daily calorie target.

**Open it:** https://amirfardinah.github.io/leanline/

- Barcodes: [Open Food Facts](https://world.openfoodfacts.org)
- Generic foods: [USDA FoodData Central](https://fdc.nal.usda.gov)
- Data is stored only in your browser (export a backup from the Plan tab).

Run locally with `start.bat` (serves on http://localhost:8765).
